R1 · Activation condition colon gate

Scope: separator between an If activation/casting condition and the costs or activation procedure it gates.

Evidence: User updated Nekroz - Valkyrus (1):

OLD: If you control no Creatures, Discard Valkyrus; prevent …
NEW: If you control no Creatures : Discard Valkyrus; prevent …

Already in corpus (colon, no space):
card evilswarm exciton knight:20
If 1 opponent controls more cards … in Hand: Detach 1; Destroy …

Current rule: Ability format says costs/targets precede ; and resolution follows (TEMPLATING.md). No rule chooses comma vs colon after an activation If condition. Corpus mixes comma (Book of Moon alt-cost prose, many mid-sentence Ifs) and colon (Exciton activation gate).

Proposal: When an If clause is an activation or casting condition that gates costs and/or the activation procedure, end the condition with : (no space before the colon), then write costs/targets, then ;, then resolution. Canonical form:

If [condition]: [costs and targets]; [resolution].

Example: If you control no Creatures: **Discard** Valkyrus; prevent all combat damage that would be dealt to you this turn.

Boundaries / keep comma:

  • Replacement / continuous If: If [event], [replacement] instead.
  • Dependent success: If you do, / If you can’t,
  • Nested or mid-resolution If that is not gating activation costs.
  • Ordinary prose lists and non-gate clauses.

Impact: docs/rules/TEMPLATING.md; Valkyrus (1), Exciton (already matches), other activation-gated If …, Cost lines on later normalize. Side effect: do not mass-convert every comma-If in the set — only activation/casting gates.
