Decisions taken here

Keyword file naming

docs/keywords/{id}.md. Lower-case kebab = keyword data, never a doc page. UPPER_CASE = module doc, published. One rule, no new directory.

Two explicit flags

preview replaces origin === 'essentia'. reminder replaces "always". Build rejects preview && !reminder — the published-HTML gate demands it.

Intros in content, not docs

website/content/section-intros/{slug}.md. A file under docs/ would auto-publish as a doc page. introFromDoc() dies.

Hero ratio = 1 / 1

Every *-hero.webp is square. Ratio matches the source, the un-zoom slows to 900 ms, hero padding shrinks to absorb the taller art.

Collapsed rail is a strip

--sidebar: 3.25rem instead of 0rem. No translateX(-100%). Both toggles stay on screen, top and bottom.

Rail is context-sensitive

Catalog everywhere; Docs | Blog switcher plus article list on reading routes. DocsRail, BlogRail and .reading-rail deleted.

Assumptions

  • graphify CLI is absent on this machine; no ticket calls it.
  • Plan artefacts live in ai-artifacts/, the repo convention.
  • Only two flag values change behaviour: mill-n.preview = true, counter.reminder = false. Draw keeps its reminder.
  • Nekroz copy drops the user's truncated fragment "Every Ritual creature ." and takes minimal grammar fixes.
  • .catalog-hero height parity is not pixel-asserted — art grows, padding shrinks.
  • Back-to-top ships in BaseLayout, so every page gets it, not only docs/blog.
  • MSE/bin/magicseteditor is a native Linux binary; release_package.py rebuild re-renders Ash Blossom without Wine.
