Decisions taken up front

Keyword rulings live in the registry

Only 16 of 73 terms have a parseable definition block in docs/. Definitions are authored in content/keywords.json with a doc back-reference. ADR 0015.

Archetypes hold members only

Membership becomes role === 'member' || linked === true. All 14 support cards move to non-archetype, keeping their archetype for relatedness. ADR 0016.

No MDX, no new dependency

The hand-written safe Markdown renderer is extended instead. Docs and blog stay zero-JS; only /decks/ needs script. ADR 0017.

Hero art is committed, not built

Converted once from original_images/ with sharp — no generative service, no API key, no network. Provenance recorded; dimensions deliberately unvalidated so a later HD upscale drops in at the same path. ADR 0018.

404 redirects; no welcome page

dist/404.html becomes a noindex meta-refresh to the base. Spec §2.3's first-visit redirect is deleted before it is ever built. ADR 0019.

Gates, not e2e

Playwright cannot run on this host. Every ticket ends in vitest plus a deterministic Node gate over dist/: check-404, check-chrome, links, budgets, dist scan.

No human step. Dependencies are installed (website/, 469 packages, Node v24.18.0) and all five source illustrations are committed, so T1 is a pure preflight gate rather than a hand-off. The whole plan runs unattended. The only optional follow-up sits outside it: overwrite a public/art/*-hero.webp with an HD upscale whenever you make one.

Standing validation

Every ticket ends with the same spine, run from website/:

  • npx vitest run <the ticket's test files> — the red-to-green proof
  • npm run content:check — content build validates without writing bytes
  • npm run build — content build, Astro, CSP hardening, dist scan, 404 gate, chrome gate
  • npm run links:check and npm run budgets:check — no dead internal link, no budget breach
  • npm run ci — format, lint, astro check, unit tests, build
