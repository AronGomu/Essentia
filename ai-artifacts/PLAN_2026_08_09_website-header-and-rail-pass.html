Decisions worth knowing

Nav island moves into the header

Only way the brand truly owns the top-left corner: the hamburger was position: fixed; left: 1rem and the header reserved padding-left: 8.8rem for it. Astro ships astro-island { display: contents }, so the island is transparent to the flex row — FindPalette already proves the shape. ADR 0027

Tint by kind, not by accent

non-archetype carries accent: relic for its page theme. That is not a section identity, so the rail ignores it and only tints kind === 'archetype'. ADR 0028

Native popover, no island

The ⋯ menu needs no JS, no hydration and no CSP change. Above 44rem an author display: flex beats the UA's [popover]:not(:popover-open) { display: none }, so the links are just an inline row. ADR 0029

Labels hide in CSS, names live in aria-label

check-chrome.mjs greps built HTML for >Learn about Essentia<, >Blog<, >Decks<, >Find</span>. Keeping the strings in <span class="label-full"> and hiding them with CSS keeps that gate green and the accessible names stable.

Warning, not error. Feedback line 8.5 asked for a warning. scripts/check-header-row.mjs prints [warn] site-header may wrap at 400px … and always exits 0; the inline page guard uses console.warn only. The Playwright single-row test is a normal red/green test — that is the thing that actually fails when the row breaks.
