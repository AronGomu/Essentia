R1 · Activation condition colon gate

Scope: separator between an If activation/casting condition and the costs or activation procedure it gates.

Evidence: Valkyrus (1) user edit:

OLD: If you control no Creatures, Discard Valkyrus; …
NEW: If you control no Creatures : Discard Valkyrus; …

Also already colon (no space):
Evilswarm Exciton Knight — If … in Hand: Detach 1; Destroy …

Current rule: Costs/targets before ;; no rule for comma vs colon after activation If.

Proposal: When an If clause is an activation or casting condition that gates costs and/or the activation procedure, end the condition with : and no space before the colon, then costs/targets, then ;, then resolution:

If [condition]: [costs and targets]; [resolution].

Example: If you control no Creatures: **Discard** Valkyrus; prevent all combat damage that would be dealt to you this turn.

Keep comma for: replacements (If …, … instead); If you do, / If you can’t,; non-gate mid-resolution If.

Impact: docs/rules/TEMPLATING.md; Valkyrus; other activation-gated comma-If lines later. Side effect: do not mass-edit every If-comma.

R2 · Hyphenated self-name uses Title

Scope: self-reference on cards whose MSE name is Archetype - Title (hyphen/en-dash separator).

Evidence:

Decisive Armor:
  Discard “Armor”  →  Discard Decisive Armor
  (not short Armor; not Nekroz - Decisive Armor)

Gungnir:
  Discard this card  →  Discard Gungnir
  (Title after separator; component form)

Valkyrus / Brionac / Trishula pattern:
  Discard Valkyrus / Brionac / Trishula

Current rule: ADR 0009 / TEMPLATING: prefer full printed MSE self-name, no quotation marks; no this card. Does not define the Archetype - Title split. Short quoted fragments like “Armor” and bare this card still appear.

Proposal: When MSE name: is [Archetype] - [Title], concrete self-reference in costs/effects uses unquoted [Title] (the full right-hand side), not this card, not quoted “Title”, and not a shorter nickname than Title. Examples: **Discard** Decisive Armor, **Discard** Gungnir, **Discard** Valkyrus. Use the full MSE name only when Title alone would be ambiguous. Other-card and archetype references keep quotes + italics as already documented.

Boundaries: Does not rename MSE name:. Does not apply to cards without the separator. P/T and other stats stay card data.

Impact: docs/rules/TEMPLATING.md (Names); Nekroz hand-trap discards; similar Burning Abyss - X self-lines on later normalize. Side effect: refines ADR 0009 for hyphenated set names.
