D1 · Immediate target references

Scope: global target-reference syntax.

Existing rule/evidence: docs/rules/TEMPLATING.md:64 requires Target 1 Creature; the target ...; docs/keywords/ACTIONS.md:7 also uses the target as noun evidence.

Conflict: Ash Blossom line 18 proposes Counter it; Book of Moon line 20 proposes turn it face down. Existing mutable cards/tests contain both styles, including test_non_archetype_creatures.py:23 and test_non_archetype_non_creatures.py:34.

Reason: current global template directly contradicts requested compact pronoun syntax.

Proposal: After a target is identified in the same ability, use it/its for one object and them/their for multiple objects. Retain an explicit noun phrase only when a pronoun would be ambiguous or a typed/linked reference is required, such as the targeted “Spellbook”.

Impact: docs/rules/TEMPLATING.md, target templates in docs/keywords/ACTIONS.md, related tests; Ash Blossom and Book of Moon when later normalized. Side effect: broad future normalization may touch many cards and must preserve possessive/plural grammar.

R1 · Printed self-name references

Scope: global self-reference syntax in concrete card text.

Evidence: Bagooska line 20 proposes Destroy Bagooska; Book of Moon line 19 proposes Cast Book of Moon .... Existing cards already mix named self-reference with this card/this Spell.

Current rule: docs/rules/TEMPLATING.md:5-9 defines formatting for full self-names and generic this card, but no preference between them.

Proposal: In concrete card rules text, prefer the full printed MSE self-name, without quotation marks, over this card, this Creature, or this Spell. Keep generic self-reference in reusable keyword/rule definitions where no concrete card name exists; use a pronoun after the object is already clear in the same sentence.

Impact: docs/rules/TEMPLATING.md, Bagooska and Book of Moon when later normalized, plus any future whole-set normalization. Side effect: longer names consume more card space; renamed cards require text sync.

D2 · Free-cast phrase

Scope: global zero-mana alternative-cost syntax.

Existing rule/evidence: Book of Moon line 19, Spellbook Magician, Upstart Goblin, docs/04_spellbook/KEYWORDS.md:5, and test_non_archetype_non_creatures.py:33 use without paying its mana cost.

Conflict: requested Book of Moon text changes that established phrase to Cast Book of Moon for free, although no explicit third rule was listed.

Proposal: For an alternative cost of zero mana, write you may Cast [full self-name] for free. for free replaces only the mana payment; additional costs and casting restrictions still apply unless separately waived.

Impact: docs/rules/TEMPLATING.md, Spellbook keyword wording, related tests, Book of Moon and other free-cast cards when later normalized. Side effect: wording is shorter but less native to Magic rules and needs an explicit additional-cost boundary.
