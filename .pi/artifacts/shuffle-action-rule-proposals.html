R1 · Compact Shuffle action

Scope: global card-text action for moving object(s) into Deck and randomizing that Deck.

Evidence: Brionac requests ability 2 Shuffle it instead of long destination prose. Same long form appears on multiple cards:

card nekroz - brionac:20
… Target 1 Creature that was put onto the Field from a Sideboard; shuffle it into its owner’s Deck.

card burning abyss - virgil:20
… shuffle it into its owner’s Deck.

card daigusto emeral:20
… shuffle them into your Deck, then Draw 1 card.

card spellbook library of the crescent:20
… shuffle the others into Deck.

card fiend griefing:18
… shuffle the target into the Deck, then …

Current rule: Closed action catalog in docs/keywords/ACTIONS.md:5 / ADR 0005 has no **Shuffle**. Prose uses lowercase shuffle … into … Deck with mixed owner/your/the Deck. Search already embeds post-search Deck shuffle as process text, not this object-moving action. Return/Bounce cover other destinations.

Ruling question: Document **Shuffle** as base action meaning “put indicated object(s) into owner’s Deck and shuffle that Deck,” omitting destination and owner phrasing?

Proposal: Add **Shuffle** to the closed base-action catalog. Definition: put the indicated object(s) into their owner’s Deck, then shuffle that Deck. Default destination is always owner’s Deck — omit into Deck, into its owner’s Deck, and into your Deck. Bold/capitalize the action like other base actions. Canonical forms after the object is clear: **Shuffle** it, **Shuffle** them. When naming objects in the same instruction: **Shuffle** 1 Creature, **Shuffle** the others.

Boundaries / exceptions:

  • Not a substitute for **Search**’s internal Deck randomization after finding cards.
  • Plain “shuffle Deck” with no moving objects stays ordinary instruction / rules prose, not this object action (example: mulligan rules).
  • Does not mean Hand, Grave, Exile, or Sideboard. Use **Bounce**, **Salvage**, **Reclaim**, or explicit Sideboard wording for those.
  • Zone Sideboard-replacement still applies when a Fusion/Synchro/Xyz/Link would move to Deck (ZONES.md).
  • Homonym nouns/participles stay plain (after the shuffle).

Impact: docs/keywords/ACTIONS.md (catalog + definition); optional cross-note only if needed. Cards: Brionac, Virgil, Daigusto Emeral, Spellbook Library of the Crescent, Fiend Griefing; tests/test_necroz_cards.py and related tests on later normalize. Side effect: adds one catalog keyword; long destination forms become non-canonical.
