Hover overlay geometry

  • height = min(0.75 × viewport.height, (viewport.width − 32) × 1046/750), width = height / (1046/750).
  • Centred on the tile centre, then clamped inside the viewport with a 16 px margin.
  • Rulings are absolutely positioned against the overlay, on the side with more room, dropped when neither side has 320 px.
  • The overlay never intercepts the pointer, so covering the tile cannot break the hover it depends on.

Card page structure and scroll

Scroll order follows from the block structure: the render sticks while the transcription scrolls, releases at the end of .card-detail, then render and text leave together and the band owns the full width. @media (max-width: 44rem) unsticks the render, unchanged.

Markdown images

  • Site-absolute sources only. External and data: throw; CSP is img-src 'self' data: and remote art has no rights record.
  • Scale must be a multiple of 5 in 5…100. An unsupported value is an error, not a silent round.
  • Consequence accepted: a site-absolute path does not resolve when the same .md is read on GitHub.
