# Spellbook rules

**Book Affinity** is retired. A former user prints full card-specific **Alternative Cost** line before abilities. Do not grant alternative cost from card name/type.

**Spell Affinity** is printed opt-in keyword only. A Spellbook Sorcery without printed keyword has no such cost.

Accepted decision evidence: [ADR 0001](../ADR/accepted/0001-spellbook-affinities-and-named-selectors.md), [ADR 0004](../ADR/accepted/0004-spellbook-effect-reconciliation.md).
