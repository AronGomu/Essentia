# Burning Abyss design

Burning Abyss is black **Aristocrats / Graveyard / Value**.

Use small, inexpensive creatures that generate value when sent to Grave. Play pattern should:

- develop Field quickly through **Descent**;
- voluntarily move creatures to Grave;
- accumulate resources;
- convert resources into Xyz/Synchro threats;
- win through generated card advantage.

Archetype should feel like Yu-Gi-Oh!'s Burning Abyss without bypassing global summon restrictions.
