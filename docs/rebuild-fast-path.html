Rebuild fast path

Where the 41 s of npm run dev and the 25.6 s of lint_mse_card_style.py go, and what the fast path replaces them with. Companion to ADR 0033 and ADR 0034.

Measured before

StepCommandWallCause
card-style lint python .script/lint_mse_card_style.py 25.6 s 1,166,598 re compiles; 512-entry cache purged every line
package rebuild python .script/rebuild_open_packages.py 41.3 s 50 of 50 cards always stale; 2 output lines, both at the end
rebuild, nothing changed same, run twice 41.3 s aggregate .mse-set is regenerated, so it never has a render/ to compare against

Why the linter was slow

After

  • _boundary_pattern(needle, ignore_case) is lru_cached → one compile per distinct needle, ever.
  • Exact substring prefilter (needle in text) before every regex → the regex runs only on candidates. Strict superset test, so results cannot change.
  • name_aliases cached; keyword and alias order sorted by (-len, text) → order no longer depends on PYTHONHASHSEED.
  • Budget: under 2 s, enforced by tests/test_lint_performance.py. Output verified byte-identical by diff.

Rebuild output protocol

Phase lines — release_package.rebuild()

rebuild LOTA-0001-Alpha_0.1 [2/5] render cards

rebuild LOTA-0001-Alpha_0.1 [2/5] render cards done (28.41s)

Five phases: aggregate manifest, render cards, print masters, package hashes, validate.

Per-card lines — export_mse_renders.py

mse.render 12/50 burning abyss - dante

mse.print 12/50 burning abyss - dante

Emitted from the post-export per-card loops. MSE itself renders in one batch subprocess with captured stdout, so those loops are the only per-card vantage point. --quiet suppresses them.

Not used

No carriage returns, no ANSI, no spinner. The output has to stay greppable in CI logs and diffable between runs.

Skip fast path

  • Excluded from the hash: the generated *_all_cards.mse-set, renders/, renders_print/, dotfiles, and the four generated JSON artifacts. They are outputs — hashing them would make every run look like a source change.
  • Skip also requires every output to exist, so a deleted render-provenance.json forces a real rebuild.
  • The stamp lives outside the package because package_hashes() hashes every package file except package-sha256.json; an in-package stamp would dirty git on every run.
  • --force bypasses. lock() always forces. Locked packages were already skipped upstream.

Not built

  • deferred Per-card partial rendering. A one-card edit still re-renders the package, because MSE exports in one batch and would need a subset mode.
  • rejected Rust/native lint engine. The cost was cache thrash, not the algorithm; a second implementation of the rules is the expensive part.
