# Shaddoll rules

## Naming

Cube names use `[optional prefix] Shaddoll - [name]`. Official `El`, `Hel`, `Nael`, `Puru`, `Qad`, `Ree`, and `Resh` remain separate from `Shaddoll`. `Curse of the Shadow Prison` and `Sinister Shadow Games` retain full names.

## Types

Do not standardize race as Puppet. Each MSE card owns its type/subtype. Global Tuner/Trap/Fusion rules apply.

## Recovery

**Shaddoll Recovery** does not absorb **On Send Grave by Effect** unless card prints that event explicitly.
