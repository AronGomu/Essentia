Related cards derivation

How website/scripts/content/related.mjs derives explicit, bidirectional quoted-name relations at build time.

This model supersedes the constraint-matching designs in ADR 0032 and ADR 0036. See ADR 0040: quoted-name relations.

Catalog shape

related: {
  archetype: string[],
  references: Reference[],
  referencedBy: string[]
}

Same archetype

archetype exists only when identity metadata carries a non-null authored archetype. It lists printed-name members matching that section's namePattern. A null-affinity staple gets an empty list, so its card page renders no Same archetype block.

References

references records each foreign archetype or card explicitly named inside double quotes in this card's rule text.

Referenced by

referencedBy is the reverse edge: cards whose quoted rule text resolved to this card or to this card's archetype section.

Quoted-name pipeline

  1. If the token occurs inside the card's own printed name, it is a self-reference and creates no quoted-name edge.
  2. If it equals a section namePattern, case-insensitively, it creates an archetype reference unless that section is the card's own archetype.
  3. Otherwise, if it matches another printed card name on a word boundary, it creates a card reference.
  4. If nothing matches, fail() stops the content build.

Curly quotes become straight quotes through shared normalizeQuotes. HTML tags are removed before extraction.

Edges, order, and display

  • An archetype reference adds the source card id to every section member's referencedBy.
  • A card reference adds the source id to only the target card's referencedBy.
  • References sort archetypes before cards, then by section label or card name.
  • Reverse edges sort by source-card name. Duplicate edges are removed.
  • Card pages render References and Referenced by, each capped at 12 entries.

Work now scales with quoted tokens instead of comparing every rule-text constraint against every card. Current live quoted tokens are self-references, so the catalog has no reference edges today; fixtures exercise all edge types.

Build guard

Any non-self quoted token that matches neither a section name pattern nor another printed card name fails with related: <id> references unknown card/archetype <token>.

Where it lives

  1. website/content/identities.json owns optional authored archetype affinity.
  2. website/scripts/content/related.mjs builds Same archetype plus quoted-name directions.
  3. website/scripts/content/orchestrator.mjs attaches the result before writing src/generated/catalog.ts.
  4. website/src/pages/cards/[id].astro renders the three conditional related-card blocks.
