The open question the probe answers

If MSE resamples from the file ratio ≥ 1.30

Frame art is loaded, then scaled to the element rect at output resolution. Dropping 750 px art into a 375-space stylesheet is enough: the print master resamples 2×, not 4×.

Work: copy images, re-pin the manifest. No coordinate maths.

If MSE rasterises in style space ratio < 1.30

The card is drawn once at card width × card height, then that bitmap is scaled. Bigger source art buys nothing.

Work: card width: 750, card height: 1046, and every geometric coordinate doubled by .script/scale_mse_style.py.

Invariants

  • The vendored tree stays hash-pinned. Any frame swap re-pins MSE/manifest.json and must leave python launcher/setup_mse.py --verify clean.
  • Locked packages are immutable (ADR 0008). They keep their SD renders; only open packages gain HD output.
  • A print master is exported, never upscaled — the template re-renders at 1500 × 2092 so text stays vector-crisp regardless of frame resolution.
  • Every render size change rewrites every render hash and package-sha256.json. That is expected, not drift.
