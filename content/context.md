# Content Folder Context

Home for all created content, including:

- Scripts
- Images
- Documentation
- Video assets and generated content
- Graphs and charts
- One-off files

## Naming

Create 1 folder for each piece of content. Prefix folder name with its creation date in ISO format:

```text
YYYY-MM-DD-content-title/
```

Keep filenames inside the folder clear and free of date prefixes:

```text
2026-08-01-legend-of-alpha-project-introduction/
├── script.md
├── thumbnail.png
└── graph.svg
```
